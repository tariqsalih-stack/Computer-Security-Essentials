# Information Technology Security & Administration (ITSA): Computer & Security Essentials

This repository contains lab documentation, Azure AI configurations, and project workflows developed during the **Computer & Security Essentials** course within the Information Technology Security and Administration (ITSA) program at MyComputerCareer.

It demonstrates practical competencies in machine learning, natural language processing (NLP), optical character recognition (OCR), and orchestrating end-to-end AI agent workflows in Microsoft Azure AI Foundry.

---

## 🛠️ Technical Skills Demonstrated

### 1. Core AI & Machine Learning Foundations
* **AI & ML Concepts:** Applied core concepts including Machine Learning, Computer Vision, Natural Language Processing (NLP), Large Language Models (LLMs), and Generative AI to analyze data and drive decision-making.
* **Dataset Auditing & Fairness:** Evaluated techniques for auditing algorithmic bias, applying pre-processing data balancing (re-weighting/oversampling), enforcing fairness constraints, and monitoring model drift[cite: 6].

### 2. Azure AI Foundry & Agent Workflows
* **Azure AI Integration:** Developed generative AI applications and endpoints, configuring prompts, parameters, and intelligent autonomous agents within Azure AI Foundry.
* **Workflow Orchestration:** Consolidated and orchestrated multi-service AI workflows, coordinating tools for automated data analysis and intelligent resource management.

### 3. NLP & Document Intelligence
* **Text Analysis:** Processed text data using NLP techniques, including tokenization, semantic analysis, and statistical text extraction via Azure AI Services.
* **Information Extraction & OCR:** Utilized Azure AI Document Intelligence and Optical Character Recognition (OCR) to extract structured data from unstructured documents, images, and media streams[cite: 5].
